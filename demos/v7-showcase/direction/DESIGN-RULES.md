# v7-showcase 디자인 규칙 (전 씬 강제 — 위반 프래그먼트는 반려)

컨셉: **계측된 시네마(measured cinema)** — 다크 스테이지 위에서 타이포가 피사체이고,
모든 장식은 "계측 눈금" 시맨틱을 가진다. 장식을 위한 장식 0.

## R1. 타이포 스케일 — 3단만 존재
- HERO: Pretendard 800, clamp(120px, 10vw, 190px), letter-spacing -0.045em, line-height 0.96, keep-all.
- LABEL: mono 스택 600, 21px, letter-spacing 0.14em, uppercase 또는 숫자.
- MICRO: mono 400, 13px, --rf-ink-subtle.
- 이 3단 밖의 폰트 크기 사용 금지. 중간 크기(본문급)가 나타나면 그 프레임은 실패.

## R2. 레이아웃 그리드 — 전 씬 공통
- 좌측 기준선 x=7.4%, 히어로 베이스라인 y=60% (±2% 허용). 씬이 바뀌어도 히어로가
  같은 자리에서 갈아끼워진다(컷 연속성). 예외: s08만 중앙 정렬 봉인.
- 크롬(모든 씬 동일): 좌상 x=7.4% y=8% MICRO `NN — SECTION`(예: `01 — HOOK`),
  우하 y=92% 전폭 헤어라인 진행 눈금 + 현재 위치 마커(폭 = 씬번호/8 지점). 그 외 크롬 금지.
  브랜드명 크롬 반복 금지(브랜드는 s08 한 번).

## R3. 박스 규칙 (하드)
- 보더 박스·카드·패널·라운드 코너·드롭섀도·배경색 칩 전면 금지.
- 허용되는 면: ① 화면 에지까지 닿는 전폭/전고 스트라이프 ② clip-path 마스크
  ③ 1px 헤어라인(계측 눈금 시맨틱 + MICRO 라벨 동반 시에만).
- "박스처럼 보이면 박스다" — 판정 기준은 렌더 프레임.

## R4. 데이터/그래프 규칙 (하드)
- 축·범례·플롯 영역이 있는 차트 UI 금지. 게이지 링·프로그레스 바 위젯 금지.
- 수치는 HERO 타이포가 직접 카운트업한다(결정론 onUpdate).
- 비율·진행은 전폭 헤어라인 위 마커 이동 또는 전고 스트라이프 성장으로만 —
  화면 자체가 그래프다. "UI 위젯처럼 보이면 실패."

## R5. 색 규칙
- var(--rf-*) 토큰만. 씬당 액센트 사용처 정확히 1곳(강조 단어·마커·플래시 중 하나).
- 성공색(--rf-success)은 s08에서 단 1회. s01~s07 등장 금지.

## R6. 모션 규칙 (비트 = 0.5106s, ~118bpm)
- 진입 구조 완성 ≤ 1비트(0.51s). 액센트 히트는 비트 정수배 시점에 배치.
- 셰이크는 s05·s07에서만 각 1회, 4스텝 이하.
- 리빙 모션 필수: 대면적 요소 brightness/opacity 브리드 1→1.2+, 주기 1.02s(2비트),
  시작 calc(var(--rf-scene-start, 0s) + 1.2s).
- 히어로 텍스트가 씬 끝까지 화면에 남는다(카피 없는 프레임 금지).

## R7. 핸드오프
- s04 끝: 스테이지가 오른쪽으로 whip-out(모션 블러) → s05가 같은 방향 whip-in으로 받는다.
- s02 끝: 액센트 마커가 좌기준선 x=7.4%, y=60%, scale 1.0으로 이동·정지 →
  s03의 카운터 첫 글자가 정확히 같은 지오메트리에서 시작(매치컷).
- 나머지 경계는 컷. 컷 직전 프레임과 직후 프레임의 히어로 베이스라인이 같아야 한다.

## R1-보칙 (2026-07-25 QC 라운드에서 추가)
- 히어로가 **단일 수치/단어(4자 이하)**인 씬은 문장 스케일 상한(190px)이 오히려 빈 프레임을
  만든다 — 이 경우 뷰포트 높이 34~40%까지 확대 허용(tabular-nums, 자간 -0.06em).
  단, 대형 수치는 반드시 눈금/마커 지오메트리와 결속되어야 한다(홀로 떠 있으면 실패).

## R-MAX (2026-07-25 R2 — 맥시멀 개정, 사용자 지시 "전부 다이나믹하게")
- 페이스: 비트 0.375s(~160bpm). 씬 4~8비트(1.5~3.0s), 총 12씬 22.5s. 모든 히트는 비트 위.
- 밀도: 씬당 히어로 + 서브라인 + MICRO 태그 클러스터 + **고스트 타이포 텍스처**(같은 단어의
  초대형 아웃라인/저투명 반복 — R1 3단 스케일 밖이지만 텍스처 레이어로 예외 허용, 가독 경쟁 금지).
- 배치 로테이션(연속 2씬 같은 패턴 금지): ①좌기준선 ②센터 펀치 ③우정렬 ④대각 풀블리드.
- 이펙트: 씬마다 주 안무 1 + 보조 레이어 1~2(그레인/글로우/스트로브/스윕). 셰이크는 피크 씬(80+) 전부 허용, 4스텝 이하.
- 유지되는 것(이건 안 풀림): 박스 금지(R3)·데이터 위젯 금지(R4)·액센트 씬당 1곳·성공색 마지막 1회·3단 스케일(텍스처 제외).
